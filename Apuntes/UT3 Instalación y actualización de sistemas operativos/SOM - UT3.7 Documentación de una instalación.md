# UT3. Instalación y actualización de sistemas operativos

## 3.7. Documentación de una instalación

La **documentación de una instalación** consiste en registrar de forma clara y ordenada la información más importante relacionada con el proceso de instalación de un sistema operativo.

Su objetivo es dejar constancia de las decisiones tomadas, los pasos realizados, la configuración aplicada y las posibles incidencias que hayan surgido durante la instalación. De este modo, el proceso puede ser revisado posteriormente y, si fuera necesario, repetido por otro técnico.

Documentar correctamente una instalación facilita el mantenimiento del equipo, la resolución de problemas y el seguimiento de las intervenciones realizadas.

No se trata de describir cada acción o cada clic efectuado durante la instalación, sino de recoger aquella información que resulte útil desde un punto de vista técnico.

En este apartado se estudiará qué información debe registrarse, cómo documentar las incidencias y los tiempos de instalación y qué utilidad tiene esta documentación en un entorno profesional.

### 3.7.1. Finalidad de la documentación

La documentación de una instalación tiene como finalidad **dejar constancia del trabajo realizado** y facilitar futuras intervenciones sobre el equipo.

Una documentación adecuada debe permitir que otro técnico pueda conocer cómo se realizó la instalación y, si fuera necesario, repetir el proceso obteniendo un resultado similar.

También resulta útil para **diagnosticar problemas**, ya que permite consultar qué decisiones se tomaron, qué configuración se aplicó y qué incidencias aparecieron durante la instalación.

Además, permite mantener un **historial técnico del equipo**, indicando cuándo se instaló el sistema, qué características tenía la instalación y qué modificaciones se realizaron posteriormente.

La documentación también sirve para comprobar que se han cumplido los requisitos previstos, como la compatibilidad del hardware, el esquema de particionado, el software básico instalado o las condiciones de uso y licencia.

Por tanto, una buena documentación facilita principalmente:

- Repetir una instalación de forma similar.
- Diagnosticar problemas o incidencias.
- Mantener un historial técnico del equipo.
- Comprobar que se han cumplido los requisitos establecidos.
- Facilitar el mantenimiento y futuras intervenciones.

### 3.7.2. Información que debe registrarse

La documentación de una instalación debe recoger la información necesaria para conocer **qué se ha instalado, cómo se ha realizado la instalación y cuál ha sido la configuración final del equipo**.

No es necesario registrar todos los pasos de forma exhaustiva, pero sí aquellos datos y decisiones que puedan resultar útiles posteriormente.

Entre la información que conviene documentar se encuentra:

#### Datos del equipo

Debe identificarse el equipo sobre el que se ha realizado la instalación. Para ello pueden registrarse datos como:

- Nombre o modelo del equipo.
- Procesador.
- Cantidad de memoria RAM.
- Capacidad de almacenamiento.
- Fecha de la instalación.

#### Planificación de la instalación

También debe quedar reflejada la planificación realizada antes de comenzar el proceso, indicando, por ejemplo:

- Sistema operativo y versión seleccionados.
- Tipo de instalación que se va a realizar.
- Medio utilizado para la instalación.
- Esquema de particionado previsto.
- Sistema o sistemas de archivos seleccionados.
- Existencia de otros sistemas operativos en el equipo.

#### Pasos relevantes de la instalación

Durante la instalación deben anotarse únicamente las decisiones o acciones más importantes, como:

- Dispositivo desde el que se inicia la instalación.
- Idioma, distribución del teclado y zona horaria.
- Particiones creadas, eliminadas o modificadas.
- Opciones especiales seleccionadas durante la instalación.
- Usuario principal creado.

No es necesario describir cada clic realizado, sino únicamente aquellos pasos que tengan importancia técnica.

#### Configuración inicial

Una vez instalado el sistema operativo, conviene registrar la configuración básica aplicada, como:

- Nombre del equipo.
- Configuración de red.
- Usuarios creados.
- Ajustes básicos realizados después de la instalación.

#### Software y actualizaciones

También debe indicarse qué software básico se ha instalado posteriormente, como navegadores, paquetes ofimáticos, controladores o herramientas de mantenimiento.

Del mismo modo, es conveniente dejar constancia de las **actualizaciones aplicadas** al sistema después de la instalación.

Toda esta información permite conocer con precisión el estado inicial del equipo y facilita futuras tareas de mantenimiento o reinstalación.

### 3.7.3. Incidencias y tiempos de instalación

Durante la instalación de un sistema operativo pueden aparecer **incidencias** que afecten al desarrollo normal del proceso. Registrar estas incidencias permite conocer qué problemas surgieron y cómo fueron resueltos.

Cuando se produce una incidencia, conviene dejar constancia de:

- Qué problema se produjo.
- En qué momento de la instalación apareció.
- Qué mensaje de error se mostró, si lo hubo.
- Qué solución se aplicó.
- Si quedó alguna actuación pendiente.

Esta información puede resultar muy útil si el mismo problema vuelve a aparecer en el futuro o si otro técnico necesita revisar la instalación realizada.

También puede ser conveniente registrar el **tiempo empleado en la instalación**. No es necesario medir cada fase con exactitud, pero sí anotar una duración aproximada del proceso completo y, si resulta relevante, el tiempo empleado en tareas concretas como la instalación de actualizaciones.

El registro de los tiempos permite estimar mejor la duración de futuras instalaciones y planificar con mayor precisión las intervenciones técnicas.

### 3.7.4. Formato y utilidad profesional

La documentación de una instalación puede realizarse utilizando diferentes formatos, siempre que la información quede recogida de forma **clara, ordenada y fácilmente consultable**.

Puede elaborarse, por ejemplo, mediante:

- Un documento de texto o PDF.
- Una hoja de incidencias.
- Una plantilla de trabajo.
- Un formulario o aplicación de gestión utilizada por la empresa.

El formato concreto es menos importante que la utilidad de la información registrada. La documentación no tiene que ser excesivamente extensa, sino contener los datos necesarios para comprender cómo se realizó la instalación y cuál fue el resultado final.

En un entorno profesional, documentar correctamente una instalación permite que otros técnicos puedan conocer el trabajo realizado, facilita el mantenimiento posterior y ayuda a evitar que se repitan errores ya detectados.

También resulta útil para mantener una cierta **homogeneidad** cuando se instalan varios equipos con una configuración similar y para justificar las actuaciones realizadas sobre un determinado equipo.

Por tanto, una buena documentación técnica debe ser **clara, precisa, ordenada y útil**, de forma que pueda servir como referencia en futuras intervenciones.
