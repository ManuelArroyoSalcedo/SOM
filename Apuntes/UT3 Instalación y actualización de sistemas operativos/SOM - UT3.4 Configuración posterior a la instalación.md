# UT3. Instalación y actualización de sistemas operativos

## 3.4. Configuración posterior a la instalación

Una vez finalizada la instalación del sistema operativo, es necesario realizar una serie de comprobaciones y ajustes para dejar el equipo preparado para su utilización.

La instalación no termina necesariamente cuando finaliza el asistente. Antes de considerar el equipo completamente preparado, conviene verificar que el hardware funciona correctamente, que el sistema dispone de la configuración necesaria y que se han instalado los componentes y aplicaciones básicas.

Entre las actuaciones más habituales se encuentran:

### Comprobación del hardware y los controladores

Debe comprobarse que los principales dispositivos del equipo han sido detectados correctamente por el sistema operativo.

Si algún dispositivo no funciona o no es reconocido, puede ser necesario instalar o actualizar su **controlador**.

Entre los dispositivos que conviene comprobar se encuentran la tarjeta gráfica, la tarjeta de red, el sonido y los dispositivos de almacenamiento.

### Configuración básica del sistema

También deben revisarse algunos parámetros básicos, como:

- La fecha, hora y zona horaria.
- El idioma y la configuración regional.
- La configuración de red y el acceso a Internet o a la red local.
- Las cuentas de usuario y sus permisos.
- El nombre del equipo.

Estos ajustes permiten adaptar el sistema al entorno en el que va a utilizarse.

### Software y mantenimiento inicial

Una vez comprobado el funcionamiento básico del sistema, pueden instalarse las aplicaciones necesarias para el uso del equipo, como navegadores, paquetes ofimáticos o herramientas específicas.

También debe comprobarse que el sistema dispone de una licencia válida cuando sea necesaria y realizar las actualizaciones disponibles.

Por último, conviene verificar que el equipo inicia correctamente y que no aparecen errores durante su funcionamiento.

Estas tareas permiten confirmar que la instalación se ha completado correctamente y dejar el sistema preparado para su utilización.
